# Solana Wallet Manager

Веб-интерфейс для управления кошельками Solana: проверка балансов, обмен токенов через Jupiter, переводы SOL/SPL-токенов и закрытие пустых связанных токеновых счетов (ATA). Построен на FastAPI.

> ⚠️ **Только для тестовых/собственных кошельков.** Приватные ключи загружаются в память сервера — не используйте с основными кошельками и не запускайте на публичном хостинге.

## Возможности

- **Загрузка кошельков и токенов** — импорт из CSV-файлов
- **Мониторинг балансов** — SOL, USDC и пользовательских токенов по всем кошелькам
- **Обмен токенов** — свопы через API Jupiter
- **Перевод активов** — SOL или SPL-токенов с проверкой баланса
- **Закрытие ATA** — возврат ренты за пустые связанные токеновые счета
- **Логи в реальном времени** — отображение логов транзакций в интерфейсе
- **Темы** — светлая и тёмная

## Требования

- Python 3.9+
- Solana RPC endpoint (по умолчанию `https://api.mainnet-beta.solana.com`, настраивается в `config.json`)

## Установка и запуск

```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt

uvicorn app:app --host 0.0.0.0 --port 8000
```

Откройте http://localhost:8000.

## Использование

1. **Загрузка кошельков** — CSV с колонками `public_key`, `private_key` (base58)
2. **Загрузка токенов** — CSV с колонками `name`, `mint`
3. **Балансы** — вкладка «Балансы», выберите кошелёк
4. **Своп** — вкладка «Swap & Close ATA»: выбор кошелька, токенов, суммы
5. **Перевод** — вкладка «Перевод»: получатель, токен, сумма
6. **Закрытие ATA** — вкладка «Swap & Close ATA», кнопка Close
7. **Логи** — вкладка «Логи» (также пишутся в `SOLANA_WALLET.log`)

## Структура

- `app.py` — FastAPI-приложение с эндпоинтами для операций с кошельками
- `api_solana_client.py` — клиент для взаимодействия с блокчейном Solana
- `config/config_load.py`, `config/config_logger.py` — загрузка конфигурации и логгер
- `config.json` — настройки (RPC, таймауты, ретраи, резерв SOL)
- `index.html`, `static/main.js`, `static/styles.css` — фронтенд
- `requirements.txt` — зависимости

## Примечания

- Свопы выполняются через публичный API Jupiter (`quote` / `swap`)
- Некорректный формат CSV вызовет ошибку — проверьте заголовки колонок
- При ошибке RPC смените endpoint в `config.json` (рекомендуется платный RPC-провайдер для продакшена)
